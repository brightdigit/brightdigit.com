**ButtondownKit currently ships with NO logo** in its README header or DocC — because
Buttondown's brand guidelines (https://buttondown.com/brand) forbid third parties from using
their mark. This is an **interim state, not permanent**: it stands only until a compliant
alternative (an original/BrightDigit-style mark) is figured out. Revisiting it later to add
a suitable logo is expected — do NOT treat logo-less as a settled decision.

When unifying package README headers, ButtondownKit is (for now) the one repo that gets a
plain markdown `#` H1 + centered description + badges, with **no `<img>` logo block**. Do
not add a *Buttondown* logo — but a compliant original logo is the intended eventual fix.
